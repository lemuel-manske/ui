# Button

Use `Button` to perform an action. Use `Link` when the user navigates to a URL.
Import `Button` from `@lemuel-manske/components` and option values from
`@lemuel-manske/design-tokens`. Component-specific names such as `ButtonSize` are type aliases.

```tsx
import { Button } from '@lemuel-manske/components';
import { Size, Variant } from '@lemuel-manske/design-tokens';

export function SaveButton() {
  return (
    <Button size={Size.MEDIUM} variant={Variant.PRIMARY}>
      <Button.Label>Save changes</Button.Label>
    </Button>
  );
}
```

`Button.Label` wraps text in a span. Plain text children are also supported.
The public standalone equivalent is `ButtonLabel`.

## Icons and status colors

Supply artwork from your own icon set inside `Icon`. The icon inherits the button's
color and stays decorative so the visible text provides the accessible name.

```tsx
import { Button, Icon } from '@lemuel-manske/components';
import { Tone } from '@lemuel-manske/design-tokens';
import { CheckIcon } from './icons';

<Button tone={Tone.SUCCESS}>
  <Icon>
    <CheckIcon />
  </Icon>

  <Button.Label>Save changes</Button.Label>
</Button>;
```

`tone` supports DEFAULT, DANGER, SUCCESS, WARNING, and INFO. It works independently
of `variant`, so status colors are available at every emphasis level. Use a visible
label or `aria-label` on an icon-only button. Use standalone `Icon` for a compact
icon action, supplying both `label` and `onClick`.

## Defaults and states

- `size` defaults to `Size.MEDIUM`; SMALL and LARGE are also available.
- `variant` defaults to `Variant.PRIMARY`; SECONDARY and TERTIARY reduce emphasis.
- `type` defaults to `button`. Use `type="submit"` explicitly for form submission.
- `disabled` disables native activation. Use visible text to explain a pending action.

Do not assume props such as `loading`, `asChild`, `href`, or `icon` exist.
Compose supported children and use the documented props. Keep an accessible name on every
button; visible text is preferred. Native keyboard activation is preserved.

See the Components/Button stories for variants, sizes, disabled and keyboard interactions,
and submission. Use the generated API reference for the complete prop contract.
